Đặt file logo nền tảng vào thư mục này (PNG vuông khoảng 128x128; cũng nhận .svg hoặc .webp).
Tên file = tên nền tảng ghi ở cột nen_tang trong Sheet hoặc lấy từ AniList,
viết thường, bỏ dấu, khoảng trắng thành dấu gạch ngang.
